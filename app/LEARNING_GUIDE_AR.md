# PFAI 8.0 — التعلم الذاتي والتدريب المستمر

تم تفعيل التعلم الذاتي المستمر افتراضيًا في نسخة Release هذه.

## كيف يعمل

1. **المعلّم**: Claude عبر `ANTHROPIC_API_KEY` يولّد أمثلة جديدة حسب المنهج.
2. **الناقد**: Claude يقيّم كل مثال ويُرفض المثال الأقل من `min_teacher_score`.
3. **التنقية**: إزالة الأمثلة القصيرة/المكررة وغير الصالحة.
4. **الذاكرة التدريبية**: حفظ الأمثلة المقبولة مع مصدرها ودرجة المعلّم.
5. **التقييم**: كل دورة تمر عبر بوابة التقييم قبل اعتبارها دورة ناجحة.
6. **تحسين النموذج**: إذا تم تثبيت `torch/transformers/peft/trl/datasets` وتحديد `PFAI_LOCAL_MODEL_ID`، ينفذ PFAI تدريب SFT/LoRA حقيقيًا. إذا لم تتوفر المتطلبات، لا يدّعي أنه درّب الأوزان؛ يسجل الحالة `blocked` ويواصل التعلم المعرفي.
7. **الحماية**: لا يتم جعل النموذج الجديد Active تلقائيًا. الترقية الإنتاجية تظل خلف موافقة صريحة.

## تشغيل التدريب الفعلي للأوزان

```bash
pip install -r requirements.txt
pip install -r requirements-training.txt
export ANTHROPIC_API_KEY='...'
export PFAI_LOCAL_MODEL_ID='path/or/hf/model'
python run_continuous.py
```

`PFAI_LOCAL_MODEL_ID` يجب أن يشير إلى نموذج محلي/قابل للتنزيل يدعمه Transformers. وجود مفتاح Claude وحده لا يعني أن Claude نفسه يتم تدريبه؛ Claude هنا معلّم/مقيّم، والتدريب الفعلي يتم على النموذج المحلي.

## السلامة

- لا يتم قبول مثال فاشل في التنقية.
- لا يتم الادعاء بإتمام SFT إذا لم ينفذ forward/backward/optimizer فعليًا.
- لا يتم الترويج التلقائي إلى Active.
- الشبكة تبقى خاضعة لسياسة PFAI.
- كل دورة وحالة تدريب تسجل في السجلات.

## تدريب الأكواد عالي الاعتمادية — Code Learning MAX

يعمل مسار تدريب الأكواد كحلقة تحقق مستقلة داخل التعلم المستمر:

1. يولّد مسألة برمجية واختبارات قابلة للتنفيذ.
2. يولّد عدة حلول Best-of-N.
3. يشغّل كل حل في Sandbox معزول وحدود وقت/ذاكرة.
4. إذا فشل الحل، يرسل الخطأ الفعلي إلى حلقة Auto-Repair محدودة المحاولات.
5. يعيد تشغيل الاختبارات بعد كل إصلاح؛ لا يعتبر الإصلاح ناجحًا من شكله فقط.
6. يضيف اختبارات حواف إضافية قبل قبول الحل النهائي.
7. يحفظ حالة الخطأ والإصلاح المؤكد كـ Regression حتى يُعاد اختباره لاحقًا.
8. لا يرقّي أي نموذج إلى Active تلقائيًا؛ الترقية تبقى خلف بوابة التقييم والموافقة.

لا توجد ضمانات واقعية بأن الكود "لن يخطئ أبدًا". الهدف الهندسي هو تقليل الخطأ عبر تحقق متعدد الطبقات، واكتشاف الفشل وإصلاحه بسرعة، ومنع تكرار الأخطاء التي تم اكتشافها.

الإعدادات في `configs/default.json` تحت `continuous_training.code_learning`.
